DECISION VIEW · 输入侧视角

选板 决策视角

矩阵答「这板球是什么」，此页答「此时该打什么」——技术图谱是输出侧，选板是输入侧：先读球高定行，再读时机定力，位置定远近。

↓高于网 / 肩

球高 —— 下压终结

只有在此高度，下半区才对你开门：全力下压收分。错过高点，窗口即关。

羽：杀球 / 扑球匹：扣杀 / 加速网：高压 / 空中挥抽乒：扣杀 / 弹击
→平于网口

球平 —— 平弧对轰

速度与角度之争：在借力与加力之间抢节奏，输快半拍即失主动。

羽：平抽 / 平推匹：drive / speed up网：平击相持 / 接发乒：挑 / 弹击 / 挤
↑低于网

球低 —— 只能向上

下半区对你关门，上半区求生：重置、挑高、造旋再起。低球求稳不求狠。

羽：挑球 / 高远匹：reset / dink / drop网：月亮球 / 挑高乒：搓 / 提 / 拉加转

上升期 · 借力

迎前吸能，快过旋转——贴 / 挡 / 快带 / 半截击 / 反弹球

高点期 · 发力

力量窗口，一击定音——扣杀 / 扑 / 高压 / 弹击

下降期 · 造旋

以旋换稳，重新组织——拉加转 / 挑高球 / 高远 / 月亮球

乒乓：台内抢先上手（摆 / 挑 / 拧），出台进入对拉；来球下旋先起旋，上旋才配发力。
羽毛球：下手必挑高，上手必下压；杀吊同出一门，唯力不同。
匹克球：球低重置，球高终结；第三拍 drop 是从底线赎回网前的门票。
网球：低月亮高高压；中场抽挡过渡，底线相持等短球。

高度定行，时机定力，位置定远近——矩阵是地图，此页是导航。同一格内的高下，靠的是练，不是选。
