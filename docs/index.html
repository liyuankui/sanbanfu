羽毛球技术 力学矩阵

任何一板出球，皆可由两维定位：出球弧线（上挑高弧 / 平射 / 下压）× 发力强度（减力软放 / 弧线控制 / 全力爆发）。羽球无胶皮咬球，劈切搓摩不造回跳之旋，只为弧线与欺骗——故纵轴取弧线，横轴取力度。九格十四技，各归其位。
