## 是什么

每个触球技术都能放进一个二维坐标系，两轴随运动物性而变：

| 运动 | 纵轴 | 横轴 | 技数 |
|------|------|------|------|
| 乒乓球 | 做功方向（↑造上旋 / →平动 / ↓造下旋） | 发力强度（借力 → 技巧 → 爆发） | 23 |
| 羽毛球 | 出球弧线（↑上挑高弧 / →平射 / ↓下压） | 发力强度（软放 → 控制 → 爆发） | 14 |
| 匹克球 | 出球弧线（同上） | 发力强度（借力 → 控制 → 爆发） | 12 |
| 网球 | 做功方向（↑造上旋 / →平击 / ↓造下旋） | 发力强度（借力 → 控制 → 爆发） | 14 |

每技附三档上手难度（●○○ / ●●○ / ●●●，按教练共识定档）。

## 为什么轴不一样

- **乒乓**：胶皮咬球可主动造旋，摩擦即发力——纵轴是「造旋方向」。
- **网球**：线床咬球如胶皮，旋转可主动造——轴与乒乓完全同构，系列里它是回归，羽球匹球才是变奏。
- **羽毛球**：球拍无胶皮咬合，劈切搓摩不造回跳之旋、只为弧线与欺骗——纵轴改为「出球弧线」。彩蛋：上手位杀 / 吊 / 高远同点三力，是乒乓「贴 / 挡 / 磕」借力三兄弟的镜像。
- **匹克球**：物理最近乒乓，但语义对调——上挑=防守重置（厨房规则所迫），下压=进攻终结。核心律：球低住左上重置区，球高入右下终结区。
